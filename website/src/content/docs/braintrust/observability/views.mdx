A project's logs page shows every row the same way until someone changes it. A **view** saves a filter, a sort and a column layout under a name, shared with everyone in the project. A **custom column** adds a column computed from each row, like the model a request used, from a field buried in its metadata.

## Save a view

```typescript title="alchemy.run.ts"
const project = yield* Braintrust.Project("Support", {});
const errors = yield* Braintrust.View("Errors", {
  objectType: "project",
  objectId: project.projectId,
  viewType: "logs",
  name: "Errors",
  viewData: { search: { filter: ["error IS NOT NULL"] } },
  options: { columnOrder: ["input", "output", "error"] },
});
```

`viewType` picks the page the view belongs to, like `logs` or `experiments`, and `viewData.search.filter` takes BTQL expressions. Moving a view to another object replaces it.

## Add a computed column

`expr` is evaluated on each row. `subtype` picks the table: `project_log` for the project's logs.

```typescript title="alchemy.run.ts"
const model = yield* Braintrust.CustomColumn("Model", {
  objectType: "project",
  objectId: project.projectId,
  subtype: "project_log",
  name: "Model",
  expr: "metadata.model",
});
```

The same column works on the list of experiments, with a `variant`:

```typescript title="alchemy.run.ts"
const commit = yield* Braintrust.CustomColumn("Commit", {
  objectType: "project",
  objectId: project.projectId,
  subtype: "experiment",
  variant: "experiment_list",
  name: "Commit",
  expr: "metadata.commit",
});
```

Changing `objectType`, `objectId`, `subtype` or `variant` replaces the column.

## Show your own page next to each span

A **span iframe** embeds a page you host beside every span in the project's traces, to render span data your way, like a chat transcript:

```typescript title="alchemy.run.ts"
const viewer = yield* Braintrust.SpanIframe("Viewer", {
  projectId: project.projectId,
  name: "Conversation viewer",
  url: "https://viewer.example.com/span",
  postMessage: true,
});
```

With `postMessage`, Braintrust sends the span's data to the page as a message instead of in the URL.
