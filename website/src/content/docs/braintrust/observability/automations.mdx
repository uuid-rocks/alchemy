An **automation** is a rule Braintrust runs on a project's data. An alert calls a webhook, posts to Slack or pages PagerDuty when new logs match a BTQL filter. An export copies logs to your cloud storage on a schedule. A retention rule deletes logs older than a number of days.

## Alert on errors

An alert fires on logs that match `btql_filter`, at most once per `interval_seconds`, so a burst of errors makes one call rather than hundreds:

```typescript title="alchemy.run.ts"
const project = yield* Braintrust.Project("Support", {});
const alert = yield* Braintrust.ProjectAutomation("ErrorAlert", {
  projectId: project.projectId,
  name: "Errors",
  description: "At most one call an hour",
  config: {
    event_type: "logs",
    btql_filter: "error IS NOT NULL",
    interval_seconds: 3600,
    action: { type: "webhook", url: "https://hooks.example.com/braintrust" },
  },
});
```

The `action` can also be `slack`, with a workspace and channel, or `pagerduty`.

## Delete old logs

A retention rule deletes logs once they are older than `retention_days`:

```typescript title="alchemy.run.ts"
const retention = yield* Braintrust.ProjectAutomation("Retention", {
  projectId: project.projectId,
  config: {
    event_type: "retention",
    object_type: "project_logs",
    retention_days: 30,
  },
});
```

Moving an automation to another project replaces it. Automations with a fixed `name` that already exist in the project are refused unless you adopt them.

Exports to cloud storage use `event_type: "btql_export"`; every field of each kind is in the [API reference](/providers/braintrust/reference/project-automation).
