A **dataset** holds the test cases an eval runs against. Each **record** has an `input`, the `expected` output, and `metadata` you can filter on. Datasets are versioned: every write is a transaction with its own id, `_xact_id`, so you can read a dataset as it was at any point.

Your Stack declares the dataset. Records come from your app, the Braintrust SDK, or the Braintrust UI.

```typescript title="alchemy.run.ts"
const project = yield* Braintrust.Project("Support", {});
const tickets = yield* Braintrust.Dataset("Tickets", {
  projectId: project.projectId,
  description: "Golden support tickets",
  tags: ["golden"],
  metadata: { owner: "support-team" },
});
```

Moving a dataset to another project replaces it, and its records are deleted with the old one. Renaming it keeps its records, but its URL keeps the first name.

## Pin a version with a snapshot

A **snapshot** gives one version of a dataset a name, so an eval can keep running against exactly those records while people keep adding to the dataset.

Take the `_xact_id` of the version you want from the dataset's records, and pin it:

```typescript title="alchemy.run.ts"
const v1 = yield* Braintrust.DatasetSnapshot("TicketsV1", {
  datasetId: tickets.datasetId,
  name: "v1",
  xactId: "1000196022104685824",
  description: "Tickets reviewed for the v1 release",
});
```

A snapshot can't move: a new `xactId` deletes the old snapshot and creates a new one under the same name.

## Read and write records from your app

`ReadWriteDataset` gives a Worker or Function a client for one dataset: `fetch`, `summarize`, `previewRestore`, `insert` and `feedback`. The host gets its own service token, with `read` and `update` on this dataset only. `ReadDataset` and `WriteDataset` grant one side.

Declare the project and dataset where the Worker can import them:

```typescript title="src/evals.ts"
import * as Braintrust from "@alchemy.run/braintrust";
import * as Effect from "effect/Effect";

export const Support = Braintrust.Project("Support", {});

export const Tickets = Effect.gen(function* () {
  const project = yield* Support;
  return yield* Braintrust.Dataset("Tickets", { projectId: project.projectId });
});
```

Then add a record for each ticket a person marks as solved, with the answer they accepted as `expected`:

```typescript title="src/api.ts"
import * as Braintrust from "@alchemy.run/braintrust";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Tickets } from "./evals.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const dataset = yield* Tickets;
    const tickets = yield* Braintrust.ReadWriteDataset(dataset);
    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const { question, answer } = (yield* request.json) as {
          question: string;
          answer: string;
        };
        yield* tickets.insert({ events: [{ input: question, expected: answer }] });
        const { data_summary } = yield* tickets.summarize({ summarize_data: true });
        return yield* HttpServerResponse.json({ records: data_summary?.total_records });
      }).pipe(Effect.orDie),
    };
  }).pipe(Effect.provide(Braintrust.ReadWriteDatasetHttp)),
) {}
```

To put the dataset back as it was at an `_xact_id`, bind `RestoreDataset` and call it with `{ version }`. A restore deletes the records added since that version, so its token also gets `delete` on the dataset, which lets it delete the whole dataset too. Bind it only where you need it; `previewRestore` shows what a restore would change without it.

## Use a dataset you didn't create

```typescript title="alchemy.run.ts"
const existing = Braintrust.Project.lookup({ name: "My Project" });
const golden = Braintrust.Dataset.lookup({
  projectId: existing.projectId,
  name: "Golden tickets",
});
```
