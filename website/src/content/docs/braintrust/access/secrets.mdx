Braintrust holds two kinds of secret for you. An **AI secret** is a model provider's API key, like OpenAI's or Anthropic's, stored for the whole organization: the playground, the AI proxy, prompts and LLM scorers call models with it. An **environment variable** is a value that functions and scorers running in Braintrust read while they run, set on the organization, one project or one function.

Braintrust encrypts both and never returns them.

## AI provider keys

Declare an AI secret from a `Config` value. `name` is what prompts and the playground know it by, and `type` is the provider:

```typescript title="alchemy.run.ts"
const openai = yield* Braintrust.AiSecret("OpenAI", {
  name: "OPENAI_API_KEY",
  type: "openai",
  secret: yield* Config.Redacted("OPENAI_API_KEY"),
});
```

For an OpenAI-compatible gateway, or a provider that needs settings, put them in `metadata`:

```typescript title="alchemy.run.ts"
const gateway = yield* Braintrust.AiSecret("Gateway", {
  type: "openai",
  metadata: { api_base: "https://llm.example.com/v1", models: ["gpt-4o"] },
  secret: yield* Config.Redacted("GATEWAY_KEY"),
});
```

A Worker can call models through Braintrust's proxy with this key without ever holding it. Declare the secret with `secret: Config.Redacted("OPENAI_API_KEY")`, without `yield*`, when the Worker binds it: a `Config` the Worker's setup reads with `yield*` is bound into the Worker. See [Prompts](/braintrust/functions/prompts#call-a-model-through-the-proxy).

## Environment variables for functions

Set a variable on a project for the functions in it:

```typescript title="alchemy.run.ts"
const project = yield* Braintrust.Project("Support", {});
yield* Braintrust.EnvVar("SearchApiKey", {
  objectType: "project",
  objectId: project.projectId,
  name: "SEARCH_API_KEY",
  value: yield* Config.Redacted("SEARCH_API_KEY"),
});
```

Or on the whole organization, with `project.orgId`:

```typescript title="alchemy.run.ts"
yield* Braintrust.EnvVar("SlackToken", {
  objectType: "organization",
  objectId: project.orgId,
  name: "SLACK_BOT_TOKEN",
  value: yield* Config.Redacted("SLACK_BOT_TOKEN"),
});
```

Changing `objectType` or `objectId` replaces the variable. Deleting a project leaves its variables behind in Braintrust, but destroying the Stack deletes each one Alchemy created.

## Rotated outside the Stack

Braintrust never returns a stored value, so Alchemy can't compare it with yours. It writes the value again on every update instead, and records when it was last written. A key someone rotates in the Braintrust UI shows up in `alchemy drift`, and repairing the drift writes yours back.

## Values from a secrets manager

`.env` is only the default. A Stack's `secrets` option reads the same `Config` values from a secrets manager instead, like Doppler or Infisical, so production keys never sit in a file on anyone's machine. Pick the source per stage:

```typescript title="alchemy.run.ts"
import * as Braintrust from "@alchemy.run/braintrust";
import * as Doppler from "@alchemy.run/doppler";
import * as Alchemy from "alchemy";
import * as Config from "effect/Config";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Braintrust.providers(),
    state: Alchemy.localState(),
    secrets: ({ stage }) =>
      stage === "prod"
        ? Doppler.Secrets({ project: "my-app", config: "prd" })
        : Alchemy.Secrets.DotEnv(),
  },
  Effect.gen(function* () {
    const openai = yield* Braintrust.AiSecret("OpenAI", {
      name: "OPENAI_API_KEY",
      type: "openai",
      secret: yield* Config.Redacted("OPENAI_API_KEY"),
    });
    return { aiSecretId: openai.aiSecretId };
  }),
);
```

Your code doesn't change: `Config.Redacted("OPENAI_API_KEY")` reads from whichever source the stage uses. See [Secret providers](/environments/secret-providers) for Doppler, Infisical, ordering several sources, and writing your own.

Secrets your own app reads while it runs, outside Braintrust, are covered in [Secrets](/environments/secrets).
