A prompt or function keeps every version it ever had. An **environment** is a label, like `staging` or `production`, that points at one of those versions, so your code asks for "the production version" instead of pinning an id. Moving the label ships a new version to everything that loads it, and moving it back rolls it back.

Environments belong to the organization, so one `production` label serves every project in it.

## Declare environments

```typescript title="alchemy.run.ts"
const staging = yield* Braintrust.Environment("Staging", {});
const production = yield* Braintrust.Environment("Production", {
  slug: "production",
  name: "Production",
  description: "Versions served to customers",
});
```

Without a `slug`, Alchemy generates one from the Stack, the stage and the logical ID. Slugs are unique across the organization, so a fixed one like `production` belongs in exactly one Stack. Every prop updates in place.

## Point an environment at a version

Assign a version to an environment in the Braintrust UI. Braintrust's API description doesn't include assigning versions, so Alchemy can't declare it yet.

Your code then loads the prompt by environment, with the Braintrust SDK's `loadPrompt`, and gets whichever version the label points at.

## Use an environment you didn't create

```typescript title="alchemy.run.ts"
const existing = Braintrust.Environment.lookup({ slug: "production" });
```
